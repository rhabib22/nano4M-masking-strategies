# nano4M-masking-strategies

Project website for **Masking Strategies for nano4M**, the COM-304 Foundation Models Spring 2026 Team 11 final project at EPFL.

Live site: https://rhabib22.github.io/nano4M-masking-strategies/

## What's here

- `index.html`: the project page itself.
- `static/css/index.css`: page styles.
- `static/images/`: the figures from the report.
- `static/pdfs/`: the final report PDF.
